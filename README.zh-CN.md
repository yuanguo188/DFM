# 捷创DFM（JCDFM）

[English](README.md) · [产品网站](https://dfm.ailgb.com) · [中文留言](https://gitee.com/yuanguo188/dfm/issues) · [海外留言](https://github.com/yuanguo188/DFM/issues)

捷创DFM是一款用于 PCB／SMT 生产资料检查的桌面软件，将图层查看、可制造性检查、测量、文件对比和工程资料导出集中在同一工作界面。

本公开仓库用于**产品介绍和问题反馈，不包含软件源代码**。

## 主要功能

- **图层查看**：2D 图形检查、3D 板预览、图层属性管理。
- **制造检查**：查看检查结果，在板图上定位问题并逐项复核。
- **测量与对比**：测量图形，比较不同图层或不同版本的资料。
- **生产资料准备**：在源资料包含所需信息的情况下，查看元件并输出 BOM、坐标、装配图和图层文件。
- **多种资料输入**：支持 Gerber、钻孔、ODB++ 及支持范围内的 PCB 设计格式；具体能力取决于安装版本和输入资料。

检测结果用于辅助工程判断，生产前仍需结合原始设计、工艺要求和制造方审核确认。

## 开始使用

1. 到[产品网站](https://dfm.ailgb.com)查看产品及下载信息。
2. 在软件中打开设计文件、文件夹或压缩包。
3. 检查图层对应关系与板框，再进行分析。
4. 从“帮助”菜单查看使用说明、项目介绍和问题反馈。

## 问题反馈

中文用户可在 [Gitee 留言](https://gitee.com/yuanguo188/dfm/issues)，海外用户可使用 [GitHub Issues](https://github.com/yuanguo188/DFM/issues)。请描述：

- 软件版本、操作系统；
- 具体操作步骤；
- 期望结果与实际结果；
- 最多 5 张与问题相关的截图。

**公开留言任何人都可能看到。请勿上传客户 PCB 资料包、账号密码或私人联系方式。** 截图请先检查是否含有保密信息。需要提供设计文件时，请与技术客服约定私密接收方式。

软件内的反馈表单与公开留言相互独立，是否可用取决于安装版本和服务端配置。技术客服、PCB／SMT 销售客服及服务号可通过软件内客服入口查看，二维码由服务端统一维护。
