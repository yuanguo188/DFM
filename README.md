# JCDFM · PCB & SMT Design Review

[简体中文](README.zh-CN.md) · [Website](https://dfm.ailgb.com) · [Report an issue](https://github.com/yuanguo188/DFM/issues)

JCDFM is a desktop application for reviewing PCB manufacturing data and preparing PCB/SMT production information. It brings layer inspection, manufacturability checks, measurement, file comparison and engineering exports into one workspace.

This public repository contains product information and community feedback. **It does not contain the application's source code.**

## What you can do

- Inspect PCB layers in 2D and preview the board in 3D.
- Review manufacturing checks and locate reported items on the board.
- Measure geometry and compare layers or revisions.
- Review components and prepare BOM, placement, assembly and layer documents when the input contains the required information.
- Work with Gerber, drill, ODB++ and supported PCB design formats. Format and export availability depend on the installed version and source data.

Analysis results are engineering aids. Confirm manufacturing decisions against the original design, fabrication requirements and your manufacturer's review.

## Getting started

1. Visit the [product website](https://dfm.ailgb.com) for product and download information.
2. Open your design files, folder or archive in JCDFM.
3. Check layer assignments and board outline before running analysis.
4. Use **Help** for usage instructions, feedback and product information.

## Feedback and support

Use [GitHub Issues](https://github.com/yuanguo188/DFM/issues) for international public feedback. Chinese-language users can use [Gitee Issues](https://gitee.com/yuanguo188/dfm/issues).

Please include the application version, operating system, steps to reproduce, expected result and actual result. Attach up to five relevant screenshots, removing confidential information first.

**Issues are public. Do not post customer PCB packages, credentials or private contact information.** If a design file is needed, arrange a private transfer with technical support. In-app feedback availability depends on the installed version and service configuration; it is separate from public Issues.

Technical support, PCB/SMT sales and the official account are available through the application's customer-support menu when configured.

## Privacy and source code

Desktop PCB parsing and analysis run locally. Online services, such as feedback, AI assistance and ordering, are separate actions and may send the information needed for those services. Review the information before submitting it.
